# Legacy World App
Expo (React Native + Web) · Supabase · Shopify.

- Desarrollo: `npm install && npx expo start --web`
- Build web: `npx expo export --platform web` (salida en `dist/`)
- Variables (Cloudflare → Settings → Build → Variables, y `.env` local): ver `.env.example`
- Esquema de base de datos: `supabase/migrations/`
