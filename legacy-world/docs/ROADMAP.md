# Legacy World App — Roadmap

Stack: Expo (React Native + TS) · Expo Router · Shopify Storefront API · Supabase (auth, DB, realtime) · Expo Push.

## Fase 1 (hecha) — Esqueleto
5 tabs (Universo, Tienda, Club, LGCY, Comunidad) + Podcast, tema de marca, datos demo, cliente Shopify.

## Fase 2 — Tienda real
Productos/colecciones de Shopify, variantes, carrito (cartCreate → checkoutUrl), login de cliente (Customer Account API).

## Fase 3 — Club
Niveles/puntos sincronizados con Shopify (metafields o Smile/Yotpo/LoyaltyLion), drops con cuenta regresiva, acceso anticipado por nivel, push.

## Fase 4 — Podcast + LGCY
Preguntas con votos (Supabase), feed de episodios (RSS/Spotify), rutinas, tracker de entrenos y gráficas, eventos con RSVP/QR.

## Fase 5 — Comunidad
Perfiles, canales, posts, DMs, moderación, networking.
